# Desarrollo

Lee `ESTADO.md` y `aula-virtual-uti/SKILL.md` antes de trabajar. Conserva la estructura y el stack de FSO: presentaciones HTML embebidas en aula local ES/EN, compilador Python, componentes JavaScript y herramientas Node/navegador. El sílabo vigente de cada materia rige su contenido académico.

El producto está en `aula-virtual-uti/`, las pruebas reproducibles en `tests/` y la distribución en `dist/`. No incorpores documentos privados, credenciales ni datos de estudiantes. Las pruebas sintéticas no equivalen a importaciones reales en Canvas o generación remota de videos.

Ejecuta `python3 -m unittest discover -s tests -p 'test_*.py' -v` para los cambios afectados y actualiza el estado y el distribuible cuando cambie el producto. Mantén documentados los problemas conocidos.
